# Click Counter Pro

Aplicacion de contador de clics moderna, desarrollada con React + Vite + Tailwind CSS, orientada a portafolio profesional.

## Caracteristicas

- UI tipo SaaS con card centrada y max width
- Tema oscuro/claro con toggle
- Persistencia en `localStorage`
- Animacion del contador al hacer clic
- Confirmacion al reiniciar
- Barra de progreso con meta de 100 clics
- Diseno responsive mobile-first

## Scripts

- `npm run dev`: inicia entorno local en modo desarrollo
- `npm run build`: genera build optimizado para produccion
- `npm run preview`: previsualiza la build localmente

## Deploy en Vercel

1. Sube el repositorio a GitHub.
2. Importa el proyecto en [Vercel](https://vercel.com/).
3. Vercel detectara automaticamente Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
